# Bookstore Inventory API

A REST API for managing bookstore authors, books, and inventory.

## Project Goal

Build a reliable backend that allows a bookstore to manage book records and track available stock.

## Technology Stack

- Python
- FastAPI
- SQLModel
- SQLAlchemy 2.x
- PostgreSQL on Neon
- Psycopg 3
- Alembic
- Pydantic Settings
- Pytest
- HTTPX

## Development Status

Project setup is in progress.

## Planned Features

- Author management
- Book management
- Inventory tracking
- Database migrations
- Search and filtering
- Pagination
- Automated testing
- Consistent API errors
